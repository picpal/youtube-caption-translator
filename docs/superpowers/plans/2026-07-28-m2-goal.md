## 반드시 지킬 제약

### 아키텍처/권한
- 서페이스는 사이드 패널 + Options 둘뿐. `action.default_popup` 되살리기 금지.
- `tabs` 권한 추가 금지. host_permissions는 youtube.com + generativelanguage.googleapis.com만.
- API 키는 Background Service Worker에서만 접근. Content/패널은 chrome.runtime 메시지로만 통신.
- 진행 스트리밍·keepalive는 Port(`chrome.runtime.connect`), 단발 조회는 `sendMessage`.
- content 스크래핑은 background가 REQUEST로 트리거(패널은 bg에만 말한다).

### 자막 획득 — 확정 방식(직접 fetch 금지)
- `youtube.com/api/timedtext` 직접 fetch는 pot 게이팅으로 200+빈본문 → **절대 사용 금지**.
- content script가 유튜브 자체 트랜스크립트 engagement 패널을 열고(스크립트 버튼 클릭 또는
  `engagement-panel-searchable-transcript` 강제 visible) `ytd-transcript-segment-renderer`
  행(`.segment-timestamp`/`.segment-text`)을 스크래핑.
- InnerTube 폴백 미구현. 패널 없는 영상 = 자막 없음 폴백(M1 게이트 재사용).

### durability — 확정 방식
- 패널 Port로 SW keepalive. 각 번역 배치 완료 즉시 IndexedDB 영속화(idempotent).
- 패널 닫힘 → 일시정지, 재개 시 `completedBatches` 다음부터. `chrome.alarms` 백그라운드 잡 미구현.
- UX 카피: "번역 중에는 패널을 열어두세요."

### 기술 게이트(각 태스크)
- pnpm 고정, Node 20+, Chrome 150. wxt + React 18 + TS 5 + Tailwind 3, MV3.
- `src/lib/` 순수 로직은 TDD(실패 테스트 → RED 확인 → 구현 → GREEN).
- 각 태스크 후: `pnpm tsc --noEmit` 0 · `pnpm test` 전체 통과 · `pnpm wxt build` 성공.
- UI 문구 한국어 / 코드·주석·커밋 영어. Conventional Commits, **태스크 마지막 스텝에서만 커밋**.

### 보안 — 가장 중요
- dev 프로필에 사용자의 실제 API 키가 있고
  `{"present":true,"maskedKey":"••••IaDg","savedAt":"2026-07-26T16:19:11.169Z"}` 상태가 끝까지 유지돼야 한다.
- dev 프로필에 `SAVE_API_KEY` / `DELETE_API_KEY` 전송 금지.
- 저장소 루트 `.env.local` 읽기·출력·삭제 금지.
- `.env.local`, `.chrome-dev-profile/`, `.chrome-dev-output/`, `.superpowers/` 커밋 금지.
- `scripts/dev-chrome.mjs`는 키 부재 시 `.env.local`을 읽어 `SAVE_API_KEY`를 보낼 수 있으므로
  **리로드에 사용하지 말 것**. 확장 리로드는 브라우저 레벨 CDP `Extensions.loadUnpacked`로만.
- 번역 원문·번역문은 로컬(IndexedDB) 저장만. 외부 전송은 Gemini 호출뿐(ToS: 개인 학습 전용).

## 검증 — 실제 Chrome 필수

표준 픽스처: `https://www.youtube.com/watch?v=zjkBMFhNj_g`
(카파시, ~1시간, ASR 전용, 트랜스크립트 패널 **1162행 실측됨**)
보조 픽스처: 수동 자막 짧은 영상 1개 + 트랜스크립트 패널 없는 영상 1개(Task 1에서 선정).

### 함정 — 반드시 인지
1. **timedtext 직접 fetch는 죽었다**(pot 게이팅, 200+빈본문). DOM 패널 스크래핑만.
2. **확장 리로드가 열린 사이드패널을 닫는다.** 리로드는 태스크 단위로 묶고, 패널 필요한데 닫혀
   있으면 NEEDS_CONTEXT로 멈춰 사람에게 클릭 요청. OS 클릭 흉내 금지, `chrome.sidePanel.open()`은
   CDP 합성 제스처를 거부한다.
3. **MV3 SW 30초 eviction** — 긴 영상은 배치별 영속화 + Port keepalive로만 견딘다. "한 번에 다 될 것" 가정 금지.
4. **트랜스크립트 패널 가상화** — 긴 영상은 스크롤로만 전량 렌더될 수 있음. Task 1에서 전량 수집법 실측.
5. **`Page.navigate`로는 SPA 경로 검증 불가** — 관련영상 앵커를 실제 `.click()` 해야 한다.

## 워크플로 규칙
- 컨트롤러 세션은 코드·설정·lockfile을 직접 편집하지 않는다.
- 구현 / 검토 / 수정을 각각 **별도 서브에이전트**로 분리 dispatch.
- 구현자 → 리뷰어 → (필요 시) fixer → 재리뷰 순서 준수.
- 실제 Chrome 검증은 CDP(9222) 읽기 전용 + 사람 클릭 요청 방식.
- 태스크 완료마다 `.superpowers/sdd/2026-07-28-m2-caption-translation/progress.md` 원장에 append.
- 모든 태스크 완료 후 opus로 전체 브랜치 최종 리뷰 → Important 이상 즉시 fix.
